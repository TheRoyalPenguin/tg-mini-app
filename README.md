# Tg Mini App

Делали этот проект командой на хакатоне. Получилась образовательная платформа прямо внутри телеграма. Пользователи читают лонгриды и проходят тесты. Админы смотрят статистику и управляют курсами.

**Зачем это вообще нужно**  
Заказчику нужна была LMS без лишних регистраций. Телега решает проблему авторизации из коробки. Человек просто жмет кнопку бота. Дальше все работает само. Дополнительно собрали бота на C# для рассылки уведомлений. Плюс прикрутили админку на React для удобной заливки контента.

**Что под капотом**  
Тут целый зоопарк технологий.
* Бэкенд написан на ASP.NET Core 8.0.
* База данных PostgreSQL общается с кодом через Entity Framework.
* Для хранения картинок и аудиофайлов подняли хранилище MinIO.
* Фронт миниаппы и админка крутятся на React в связке с Tailwind CSS.

Авторизацию завязали на валидацию строки `initData` от самого телеграма. Секьюрно и без паролей. Еще прикрутили Redis для кэширования. Конвертация файлов DOCX в HTML работает прямо на лету через библиотеку Mammoth. Накостыляли как могли. Но оно завелось.

**Архитектура и ветки**  
Свалка веток отлично видна на скрине. Основная разработка шла в ветках `main` и `develop`. Плюс есть куча именных рабочих веток. Например таски разработчиков `cl9wnn`, `danis` и `yuizhey`. В репозитории лежат отдельные папки для фронта, бэка, админки и телеграм бота. Запускается весь этот комбайн через единый файл конфигурации докера. Из коробки сразу поднимаются база данных с файловым хранилищем и сам бэкенд.

**Известные косяки**
Кода много. Времени было мало. Тестов нет вообще. Вся авторизация жестко завязана на токене бота. Замокать телегу для локальной разработки тот еще квест. Мобильная верстка местами едет. Надо фиксить отступы в компонентах. Документацию API через Swagger мы прикрутили.
